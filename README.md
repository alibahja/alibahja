### PyTorch Transformer — English-to-Italian Translation

Implemented components include:

- Multi-head attention

- Custom layer normalization
- Residual connections
- Feed-forward networks
- Encoder and decoder stacks
- Label smoothing
- Greedy decoding
- Beam search experimentation

The project includes the complete training and inference pipeline for English-to-Italian machine translation.

## Research

### ReSTTA-UAV: Reliability-Gated Teacher-Student TTA for UAV Object Detection

**Co-author | Lebanese American University**

Developed a reliability-gated teacher-student framework for UAV object detection under real-world domain shifts, including haze, low-light conditions, motion blur, and altitude variation.

- Improved F1 from **0.111 to 0.311**
- Improved pseudo-label precision from **0.060 to 0.667**
- Reduced update overhead by **82%** compared with the naive baseline

**Technologies:** Python, PyTorch, YOLO
